### 🌟 Overview

Laundry Pickup & Delivery Management System is an intelligent order management platform that revolutionizes laundry service delivery through smart scheduling, real-time tracking, and customer-centric design.

It empowers customers to schedule pickups, track orders in real-time, and manage laundry requests seamlessly, while enabling administrators to optimize service delivery, maximize operational efficiency, and enhance customer satisfaction.

⸻

### ✨ Features

### 👨‍💼 Customer Features

* User Registration & Authentication with Email Verification
* Schedule Laundry Pickup Requests with Date & Time Selection
* Select Service Types (Wash, Dry Clean, Iron, Specialist Care)
* Real-time Order Tracking & Live Status Updates
* Complete Order History & Previous Orders Management
* Profile Management & Personal Preferences
* Notification Alerts for Pickups & Deliveries
* Order Ratings & Reviews System

🚀 Getting Started

Clone Repository

```
git clone https://github.com/KawyaDissanayaka/laundry-pickup-delivery-management-system-frontend.git
```

Navigate to Project

```
cd laundry-pickup-delivery-management-system-frontend
```

Install Dependencies

```
npm install
```

Configure Environment

Create a `.env` file in the root directory:

```
REACT_APP_API_URL=http://localhost:8080/api
REACT_APP_API_TIMEOUT=30000
REACT_APP_NODE_ENV=development
REACT_APP_LOG_LEVEL=debug
```

Run Frontend Application

```
npm start
```

Application runs at:

```
http://localhost:3000
```

Build for Production

```
npm run build
```

Backend Integration

The frontend connects to the backend REST API:

```
http://localhost:8080/api
```

Ensure the backend server is running before starting the frontend.

## 💡 Troubleshooting Guide

### Common Issues & Solutions:

**Issue: Port 3000 already in use**
```bash
# Solution 1: Use different port
PORT=3001 npm start

# Solution 2: Kill process on port 3000
lsof -ti:3000 | xargs kill -9
```

**Issue: API Connection Failed**
```
✓ Verify backend server is running on http://localhost:8080
✓ Check REACT_APP_API_URL in .env file
✓ Ensure CORS is enabled on backend
✓ Check network tab in browser DevTools
```

**Issue: npm install fails**
```bash
# Solution: Clear cache and reinstall
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

**Issue: Build fails**
```bash
# Solution: Check Node version
node --version  # Should be 16.x or 18.x

# Clean and rebuild
npm run build
```
